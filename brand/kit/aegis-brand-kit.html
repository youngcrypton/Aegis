Aegis brand kit

Hedge drawdowns. Never get liquidated. This kit defines how the AEGIS mark, colour, type and layout are used across the landing page, the dashboard, social profiles and any image we make. It is built from the landing page itself, so the two always match.

Version 1.0October 2026Owner: AEGIS core team

The mark

Three blades rising from one base line, read as a hedge: each blade is one layer of protection. Use the mark on its own where space is tight, and the lockup wherever the name must be read. Never redraw it; use the SVG files.

Colour

Every colour has one job. Teal means live, healthy or the primary action. Amber means a hedge is open or a trigger has been reached. Rose means liquidation risk or a refused action. Nothing else carries meaning, so nothing else takes these roles.

The Blade gradient is the brand ground. Dark (top) for dark mode, light (bottom) for light mode. It runs at 135 degrees with stops at 0, 45 and 100 per cent.

Typography

Two families and no third. Marcellus carries the display: wordmark, headlines and figures that matter. Inter carries everything else, including every table, label and number that changes. Mono is not part of the system.

Graphics

The product's own picture is the graphic. The hedge chart, the trigger line and the glow of the blades are the only motifs. Do not add stock imagery or abstract decoration.

Trigger lineA dashed amber line marks the level where the hedge opens. Use it on any chart that shows a threshold.
Two-line comparisonRose for the collateral falling, teal for the hedge rising. The two meet and hold the net position flat.
GlowSoft teal light behind the mark on dark grounds only. Never on light.

Voice

Say what the thing is and what it does. The product is about money and risk, so the copy is calm, exact and never excited.

Hedge drawdowns. Never get liquidated.

Protect your portfolio with our amazing hedging magic!

Launch app terminal

Start your journey now 🚀

You're doing amazing, keep it up!

  • Sentence case for headlines, labels and buttons. Never all caps, except the one meta line.
  • Active voice. A button names the action it performs.
  • Figures are exact and carry their units: 12.40 ETH, $22,000, 1.20.
  • No emoji, no exclamation marks, no greetings in the interface.
  • Every claim must match the protocol specification. If the spec does not say it, the page does not say it.

Motion

Motion is used sparingly and always means something changed. The splash is the one brand moment; everything else responds to a person's action.

Splash
Three palettes combine in one pass, graphite, lavender, then the Blade ground, and hand off to the page. Once per load. Skippable with a click or key.
Chart draw-in
Each mechanics panel draws its line once when it enters the view. Holds still after that.
Aurora and stars
Slow ambient drift on the dark ground only. The viewer can pause it.
Feedback
Controls respond within 150 ms. Changes to figures ease over 300 to 500 ms.
Reduced motion
All motion stops. Charts and figures show their final state.

Open items

What this version does not yet settle. Each item needs a decision before the kit is final.

Wordmark case
The site writes "Aegis" in Marcellus. The X header writes "AEGIS" in tracked caps. Pick one as the standard; this kit uses "Aegis" for running text and the lockup.
Font in images
The X header and profile graphics are set in Poppins as a stand-in. Re-render them in Marcellus once the font file is supplied.
Iconography
No icon set is defined. Pick one line weight, match it to Inter's 400 weight, and add it here.
Dashboard
The dashboard is not yet built. The "Open dashboard" link is still a placeholder, so this kit does not define dashboard components.
Sentinel latency
The page states "under 70 ms" for a read and "under 78 ms" for the average SLA. Confirm both against the specification before publishing.
