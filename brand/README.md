# AEGIS brand

The brand kit is the single standard for every user interface in this project: the landing page, the dashboard and app screens, social profiles, and any image or graphic we make.

- **Kit (read first):** `brand/kit/aegis-brand-kit.html` (open in a browser; light and dark).
- **Tokens (import in UI code):** `brand/kit/tokens.css`.
- **Rules for agents and contributors:** `AGENTS.md` at the repo root. `CLAUDE.md` imports it.
- **Social assets:** `brand/x/`.

Open decisions, not yet confirmed by the owner: wordmark case ("Aegis" vs "AEGIS") and the navy used on white backgrounds (`#1C2238`). Until they are confirmed, follow the kit as written.
